# IMM Design Canon

Источник: `design/references/` (3 мокапа библиотеки + лого). Применяется с Phase 1.
Реализация — WPF-UI (Fluent), тёмная тема. Всё ниже — токены, а не пиксель-перфект копия.

## Layout (3 колонки)

| Зона | Ширина | Содержимое |
|------|--------|------------|
| Сайдбар | ~230px | Лого IMM + подзаголовок, навигация (Библиотека / Сканер / Настройки), внизу статус-индикатор («Готово · MO2 не запущен») |
| Контент | * | Заголовок «Библиотека» + счётчик, тулбар (сетка/список, сортировка, поиск, фильтр), сетка карточек 3 колонки |
| Детали | ~350px | Обложка, название + версия, инфо-строки (иконка + label слева, value справа), кнопка ЗАПУСТИТЬ, вторичные кнопки, Заметки, Теги |

## Палитра (тёмная, холодный navy)

| Токен | Значение | Использование |
|-------|----------|---------------|
| `Bg.Base` | `#0D1420` | Фон окна |
| `Bg.Sidebar` | `#0A101B` (или overlay) | Сайдбар |
| `Bg.Card` | `#151D2E` | Карточки, панели деталей |
| `Bg.CardHover` | `#1A2438` | Ховер карточки/навигации |
| `Accent` | `#2E8BFF` | Кнопка ЗАПУСТИТЬ, выбранная карточка, активный нав |
| `Accent.Cyan` | `#38BDF8` | Альтернативный акцент (лого-кольцо, вторичные подсветки) |
| `Text.Primary` | `#F5F7FA` | Заголовки, значения |
| `Text.Secondary` | `#8A94A6` | Подписи, label-ы инфо-строк |
| `Success` | `#2ECC71` | Snackbar «запущено», чекмарки |
| `Warn` | `#E67E22` | «Требует проверки» (детект неоднозначный) |

Лого: шестерёнка `#3E5A7A` + кольцо `Accent.Cyan` + знак бесконечности `#E8B84B` (amber), фон — круг `#0D1526`.

## Компоненты

- **Карточка сборки**: обложка 16:9 (радиус 8), заголовок 15–16 semibold, строки «игра / движок» с иконками, дата последнего запуска + время в игре (иконки календаря/часов), меню `...`. Выбранная: рамка `Accent` 2px + бейдж-галочка в правом верхнем углу обложки.
- **Инфо-строка деталей**: иконка (16) + label `Text.Secondary` слева, value `Text.Primary` справа. Строки: Игра, Движок, Последний запуск, Время в игре, Версия сборки, Автор, Категория/Теги.
- **ЗАПУСТИТЬ**: полная ширина, высота ~44, радиус 8, `Accent`, иконка Play, текст caps. Ниже — две вторичные кнопки 50/50: «Бэкап профиля», «Папка сборки».
- **Нав-элемент сайдбара**: активный — заливка `Bg.CardHover` + левая полоска `Accent` 3px, иконка + текст.
- **Статус внизу сайдбара**: точка (Success/gray) + «Готово» / состояние MO2.
- **Snackbar** (низ-право): иконка Success/Info + текст, автоскрытие.
- **Теги**: чипы-капсулы на `Bg.CardHover`, текст `Text.Secondary`.

## Типографика

- Заголовок страницы: 26–28 semibold
- Подзаголовок/счётчик: 13 `Text.Secondary`
- Название сборки в деталях: 20–22 semibold
- Карточка: заголовок 15 semibold, вторичные строки 13
- Инфо-строки: 13 (label) / 13 (value)
- Шрифт: Segoe UI (системный) — лезет из WPF-UI по умолчанию

## Маппинг на WPF-UI

| Референс | Контрол |
|----------|---------|
| Сайдбар | `ui:NavigationView` (PaneDisplayMode=Left, компактный) |
| Карточки | `ui:Card` + кастомный DataTemplate (Grid/ListView WrapGrid) |
| ЗАПУСТИТЬ | `ui:Button` Appearance=Primary |
| Вторичные кнопки | `ui:Button` (стандартные) |
| Инфо-строки | Grid: `ui:SymbolIcon` + TextBlock ×2 |
| Snackbar | `ISnackbarService` (уже подключён) |
| Диалоги | `IContentDialogService` (уже подключён) |
| Чекмарка выбора | `ui:Badge` / SymbolIcon поверх обложки |
| Тумблер сетка/список | `ui:ToggleSplitButton` или 2 `ui:ToggleButton` в `ui:ButtonGroup` |
| Поиск | `ui:AutoSuggestBox` |

## Правила

- Иконки — только SymbolIcon (Symbol Fluent иконки), никаких растровых в UI
- Обложки сборок — из папки сборки (`cover.png/jpg` в корне, опционально), кэш в памяти
- Даты в UI — локальные, внутри — UTC (инвариант библии)
- Тексты UI — русские, код — английский (инвариант библии)
