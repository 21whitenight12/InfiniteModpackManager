# Infinite Modpack Manager — Agent Rules

Десктоп-приложение: C# / .NET 10, WPF + WPF-UI (lepoco, Fluent). **Библия проекта — `IMM.md` в корне, опираться строго на неё.**
Память проекта: `.hermes.md` (автозагрузка Hermes).

## Git (строго)
- Репо содержит ТОЛЬКО файлы проекта: планы, research, личное — в `.gitignore`, не коммитим
- `.gitignore` подключён ДО первого коммита
- Репо приватный (GitHub: `21whitenight12/InfiniteModpackManager`); пушить разрешено

## Правила кода
- Коммиты с осмысленными сообщениями; после каждой фазы — коммит
- CHANGELOG.md: новые версии только в начало (когда появится)
- Минимум кода: stdlib/платформа > новая зависимость; никаких обёрток ради абстракций
- Никакой бизнес-логики в code-behind (для WinForms/WPF: сервис → интерфейс → UI-слой)
